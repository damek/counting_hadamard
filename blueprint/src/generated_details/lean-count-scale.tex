\paragraph{Meaning.}
This is the normalization used to turn normalized counts into actual Hadamard counts. It is the factor by which the raw count is divided in the main theorem.
\paragraph{Formal Lean definition.}
\begin{verbatim}
def countScale (n t : ℕ) : ℝ :=
  (2 : ℝ) ^ (4 * n * t) * gaussianScale n ↑t
\end{verbatim}
