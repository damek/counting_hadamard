This is the normalized counting quantity hadamardCount divided by the ambient power-of-two scale. The main asymptotic theorem is first proved for this normalized object and only then rewritten into the final count-scale statement.

def normalizedCount (n s : ℕ) : ℝ := (hadamardCount n s : ℝ) / (2 : ℝ) ^ (n * s)
