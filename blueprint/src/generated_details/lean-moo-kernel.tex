\paragraph{Meaning.}
This is the symmetric zero-diagonal kernel built from lambda that lets the project's characteristic function comparison fit into the generic quadratic-form framework.

\begin{verbatim}
def mooKernel (n : ℕ) (lam : Fin n → Fin n → ℝ) : Fin n → Fin n → ℝ :=
  fun i j => if i = j then 0 else lam (min i j) (max i j) / 2
\end{verbatim}
