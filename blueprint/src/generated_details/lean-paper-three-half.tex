\begin{verbatim}
theorem paper_threeHalfInfluenceSum_eq_eight_kernelInfluence_sum
    (n : ℕ) (lam : Fin n → Fin n → ℝ) :
    threeHalfInfluenceSum n lam
      = 8 * ∑ k : Fin n,
          kernelInfluence n (mooKernel n lam) k
            * Real.sqrt (kernelInfluence n (mooKernel n lam) k)
\end{verbatim}
\begin{proof}[Proof sketch]
Expand the definitions of mooKernel, kernelInfluence, and threeHalfInfluenceSum. Each row influence is four times the corresponding kernel influence, so summing the three-halves powers gives the factor of eight.
\end{proof}
