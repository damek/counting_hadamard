\chapter{Module guide}
\label{chap:modules}

File-by-file map of the Lean formalization.

\begin{description}
\item[\texttt{HadamardCn3Defs}]
  Core definitions: $d=\binom{n}{2}$, edge type, $\psi$, $\|\lambda\|^2$,
  Gaussian scale $\Ahat$, count scale $A_{n,4t}$, normalized count
  $N_{n,4t}/2^{4nt}$, matrix structure.

\item[\texttt{HadamardCn3TorusCount}]
  Torus counting infrastructure: Fourier inversion, prefactors,
  combinatorial cycle formulas, hypercontractive bounds, Gaussian
  radial moments, quartic and quintic cumulant estimates.

\item[\texttt{HadamardCn3Moments}]
  Moment bounds: fourth, sixth, and eighth moment estimates for
  polynomial corrections to the Gaussian integrand.

\item[\texttt{HadamardCn3MOO}]
  Mossel--O'Donnell--Oleszkiewicz kernel infrastructure: row influence,
  kernel influence, the three-halves influence sum $J(\lambda)$.

\item[\texttt{HadamardCn3WeakInvariance}]
  Lindeberg replacement proof: hybrid vectors, Taylor expansion,
  moment matching, and the weak comparison theorem
  (Lemma~\ref{lem:weak-comparison} and Corollary~\ref{cor:weak-comparison}).

\item[\texttt{HadamardCn3QuarticFiber}]
  Quartic fiber analysis: peeling identity, ordered cycle formula,
  and pointwise quartic bounds.

\item[\texttt{HadamardCn3LocalGapBridge}]
  Bridge estimates: log-expansion, small-ball decay, cubic phase bound,
  core-to-corrected-to-quartic-to-cubic bridge chain, primary annulus
  and far-shell integral bounds.

\item[\texttt{HadamardCn3LocalGapResidual}]
  Residual estimates: primary core contribution, shell transport,
  annulus bound, far-shell bound, and the quantitative residual theorem
  (Proposition~\ref{prop:residual-estimate}).

\item[\texttt{HadamardCn3LocalGapFixedN}]
  Fixed-$n$ analysis: shrinking-box infrastructure with
  $\delta_t=t^{-2/5}$, fixed-$n$ normalized-count and count asymptotics
  (Lemma~\ref{fact:fixed-n}).

\item[\texttt{HadamardCn3Asymptotics}]
  Intermediate bridge: primary-box estimate on the Gaussian scale,
  normalized-count asymptotic combining primary and residual.

\item[\texttt{HadamardCn3ShortMain}]
  Paper-facing theorems: Theorem~\ref{thm:main-intro} and
  Corollary~\ref{cor:uniform}, with the count normalization.

\item[\texttt{HadamardCn3ResidualBase}]
  Residual base estimates: supporting lemmas for the residual route.
\end{description}
