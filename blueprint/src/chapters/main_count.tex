\section{Main Count Theorem}
\label{chap:main-count}

This chapter contains the endpoint theorem chain for the number of partial
Hadamard matrices. The key Lean-only bridge result here is
\texttt{normalizedCount\_asymptotic}, which transports the primary-box estimate
to the normalized count before the final count normalization.
