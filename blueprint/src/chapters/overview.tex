\section{Overview}
\label{chap:overview}

This blueprint is the canonical human-facing formalization map for the active
route formalizing arXiv:2603.30013. It is not a replacement for the paper; it
is the synchronized map from paper statements to Lean declarations, Lean-only
bridge results, module ownership, and the active dependency route. The local
TeX source \texttt{documents/short.tex} remains in the repository for
synchronization and validation.

The guiding principle is architectural honesty:

\begin{itemize}
\item paper-labeled statements remain explicit blueprint items,
\item Lean-only bridge theorems appear when the formal route actually uses them,
\item module ownership is recorded so readers can jump into the live source only
  when they want more detail.
\end{itemize}
